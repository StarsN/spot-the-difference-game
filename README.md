Twin Town is a spot-the-difference game: two pictures that look the same, seven small things changed. Three hand-drawn scenes — Harbor Dawn, Lantern Market, Moon Garden — each with seven differences to ring. Click a difference on either picture, watch the counter tick down, and mind your three hearts: wrong clicks cost one. Hints, a timer, time bonuses, synthesized sound effects, and full keyboard play (arrow keys move the crosshair, Enter clicks, H hints) round it out. All art and sound are generated in code — no image or audio files, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
